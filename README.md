# NickApp

Personal daily-priorities scorecard. Full spec: [nickapp-spec.md](nickapp-spec.md).

- `web/` — field app (PWA), deployed to GitHub Pages by `.github/workflows/pages.yml`.
- `apps-script/` — data service + Trends, bound to the NickApp Sheet, pushed with clasp.

## First-time Sheet setup

In each Sheet's script editor (Extensions → Apps Script), run `setup` and approve the
permissions. It creates the tabs, seeds Targets / CommonExercises / ReadingList / Users,
creates the Drive photo folder, and logs the personal install link. It is safe to re-run.
`showMyUrl` prints the install link again.

## Tests

The pace rule lives in `apps-script/Pacing.js` and is shared by Apps Script, the PWA,
and Node:

```
node --test tests/*.test.js
```

## Local preview

```
node tools/serve.js        # copies Pacing.js into web/js, serves web/ on :8080
```

Open http://localhost:8080/?demo for a believable week with no network or storage.
Icons are generated by `node tools/make-icons.js`.

The manifest deliberately has no `start_url`: it defaults to the page URL, so the
installed app launches with its `?u=<token>` (iOS home-screen apps do not share storage
with Safari, so the URL is the only reliable carrier).

## Deploy

**PWA:** push to `main`; the Pages workflow publishes `web/`.

**Apps Script** (run from `apps-script/`). Test first, then live. Redeploying to the
existing deployment id keeps the `/exec` URL stable.

```powershell
# test  (-P needs a Windows backslash path; clasp 3.4 rejects forward slashes)
clasp -P "$PWD\.clasp.test.json" push -f
clasp -P "$PWD\.clasp.test.json" redeploy AKfycbwRVJ2wlNJf0-Y9fJjoI1fqMPsBPRva8kWU8YyzCFN102TsGdJdsaAqkuFC-1nNYXMebw -d "msg"

# live
clasp push -f
clasp redeploy AKfycby48oBTLtSi5hHRezoWmb22fvTAUu2GAvmQJ8MO6AiM_A7NMY3iFoMZUGsvO-Hj_EJ- -d "msg"
```
